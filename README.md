Overview
This project is a complete statistical study based on real-world data collected through a survey. The goal is to apply theoretical concepts from statistics to a practical scenario by designing a survey, collecting raw data, analyzing it, and presenting meaningful insights using visualizations.
The analysis focuses on identifying trends, patterns, and relationships within the collected data using descriptive statistics and graphical representations.

What This Project Does
Designs a structured survey targeting a specific population
Collects real responses using online tools (e.g., Google Forms)
Cleans and organizes the collected dataset
Computes key statistical measures such as:
Mean
Median
Mode
Generates charts and graphs to visualize trends
Interprets the results to evaluate a research hypothesis

How to Use This Project
Open the Research Report to understand the problem, methodology, and conclusions
Review the dataset (.CSV) to see the raw collected data
Open the Jupyter Notebook to:
Follow the analysis step-by-step
Reproduce the results
Understand how visualizations were created
